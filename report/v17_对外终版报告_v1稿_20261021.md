## 摘要

本报告记录神经元质量判别器（keep/reject 二分类任务）第 17 版（v17）的完整训练与验证结果。v17 采用干净语料 558 条（keep 250 / reject 308）、基座模型冷起动、显式类别权重 1.0 的训练配方，经 5 个 epoch 满跑收敛；训练后执行三基准评测与三档泄漏复核，**泄漏复核三维（文本 / pair_id / 组合语义）全部为 0，由两个独立执行方一致复现**。v17 达到内部成立标准，可作为后续版本（v18）的冻结基线。

## 一、任务与数据

- **任务**：给定一对神经元组合（标签 × 标签），判定其质量归类为 keep（保留）或 reject（丢弃）
- **基座模型**：Qwen2.5-0.5B-Instruct（公开模型），PEFT LoRA（r=16, α=32），CPU fp32 训练
- **训练语料**：558 条 = keep 250 + reject 308（reject 占比 55.2%）
- **语料来源与清洗**：多来源合并后经三重硬拦停过滤（评测集命中剔除 / 丢头检查 / 组合语义级零交集）；语料 sha256 = `fed6726ecf0f05eabb068a37df4414132e468bb304675a301fa927a722dc0750`（436321 字节 / 558 行）
- **头部字段登记（三口径，必须带标签使用）**：严格六字段 116（判据）/ 宽松口径 118（参考）/ 半头行 2（HYA-REJ-001、HYA-REJ-008，cluster_summary 类型天然无「来源记忆」字段）

## 二、训练配置与过程

| 项 | 值 |
|---|---|
| 起步方式 | 基座冷起动（不加载任何历史适配器） |
| 优化超参 | 5 epochs / lr 5e-5 / batch size 2 / seed 42 |
| 类别权重 | 显式 1.0（唯一计分配方） |
| 训练量 | 1395 步满跑，墙钟约 3.2 小时（CPU） |
| loss 曲线 | 1.604 → 0.540 → 0.316 → 0.180 → 0.107（逐 epoch 均值，平滑收敛） |

## 三、评测结果（三基准，诊断参照）

| 基准 | v17 结果 | 历史参照 | 判读 |
|---|---|---|---|
| basis63（63 条固定基准） | 52/63 = 82.5% | 参照系 55/63 = 87.3% | 低于参照系 = 预期（学泛化，非背题） |
| val168（168 条验证集） | reject 召回 86/100 = 86.0%；keep 召回 44/68 = 64.7% | 参照系文本级命中 120/168 | 泛化判断力健康 |
| fitcheck79（79 条拟合检查） | 7/79 = 8.9% | 参照系 79/79 = 100% | 远低于 90% 异常高判据 = 无泄漏信号 |

fitcheck79 历史序列（同批 79 条）：参照系 100% → v13 24.1% → v14 77.2%（带头版格式，与裸闸不可比）→ v15 0.0% → v16 12.7% → **v17 8.9%**。三基准解析失败均为 0。

**判读口径说明**：裸闸分数**低于**历史参照系为预期结果（说明模型学到泛化判别而非记忆题目）；裸闸分数**异常高逼近参照系**才是泄漏信号。v17 三闸全部低于或远低于参照系，无泄漏信号触发。

## 五、过程披露（如实登记）

**训练中断事故**：训练过程中发生一次机器关机导致的训练中断（事件日志坐实为人工干净关机），中断于 step 115/1395，因当时检查点策略仅按 epoch 末保存，该次进度全部作废。次日以完全相同的配置（同语料 sha、同 seed、同超参）重启，**一次满跑完成，无第二次中断**；重启前与判读后两个时点复核输入语料 sha256 逐字节一致（未漂移）。

**工具链缺陷与修复**：判读阶段曾因 Windows 系统账户管道编码缺陷导致评测脚本输出崩溃（`UnicodeEncodeError`），且原编排逻辑在子进程失败时不抛错、引发静默死亡。根因经精确复现实证（同一错误逐字一致；修复后干净通过），定性为工具链缺陷，不影响模型与判读结果。修复：强制 UTF-8 输出环境 + 子进程非零退出即抛错并中止判读链。修复后全链重跑通过，本报告数字以修复后重跑为准。

## 六、已知边界（两条，不得在引用本文时省略）

1. **三基准裸闸数为训练方单方读数**：独立复现方无 GPU 环境且模型文件不在其可读域，第三方推理复现未实施。本次三闸为异常低方向，单方读数不构成放行风险；若需第三方读数，可另行提供模型与评测集。
2. **head 三口径必须带标签使用**：严格 116 / 宽松 118 / 半头行 2，禁写单一裸数字，禁把「151 − 33」派生式当登记值（该式与宽松口径数值相等属巧合）。
